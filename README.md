# LPs

Central de landing pages para demonstração e homologação.

## Organização

Cada projeto ocupa uma subpasta independente, com seu próprio HTML, CSS, JavaScript e imagens. Use caminhos relativos. Não altere arquivos de outros projetos ou configurações globais sem autorização.

Antes de publicar uma alteração, consulte a versão atual da branch `main` e mantenha o escopo restrito à pasta do projeto. Não utilize force push.

Hospedagem prevista: Vercel, com o repositório inteiro como diretório raiz.
